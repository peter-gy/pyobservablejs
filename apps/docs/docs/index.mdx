# pyobservablejs

`pyobservablejs` embeds reactive Observable notebooks in Python. Author cells or
load an existing notebook, render all or selected cells, synchronize Python
values, read structured browser results, and inspect the dependency graph.

It works in JupyterLab, marimo, VS Code notebooks, Google Colab, and other
[anywidget](https://anywidget.dev/) hosts.

```sh
uv pip install pyobservablejs
```

Try it in a disposable marimo environment:

```sh
uvx --with pyobservablejs marimo edit notebook.py
```

## Live notebook

Hover a dot to inspect a measurement. `Plot` and the `penguins` sample are
Notebook Kit builtins loaded in the browser. They require browser network
access.

```marimo-config
requires-python = ">=3.11"
dependencies = ["pyobservablejs"]
```

```python
import marimo as mo
import observablejs as obs

notebook = obs.Notebook(
    obs.js(
        """
        Plot.dot(penguins, {
          x: "culmen_length_mm",
          y: "culmen_depth_mm",
          fill: "species",
          r: 4,
          tip: {
            // This example references a theme variable used by mdx-marimo.
            // Replace it with a CSS color or remove `fill` in another host.
            fill: "var(--marimo-island-background)"
          }
        }).plot({
          height: 320,
          color: {legend: true},
          x: {grid: true, label: "Bill length (mm)"},
          y: {grid: true, label: "Bill depth (mm)"}
        })
        """,
        key="penguins_plot",
    ),
)

mo.ui.anywidget(notebook.view())
```
