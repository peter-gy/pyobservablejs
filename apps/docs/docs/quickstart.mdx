# Quickstart

`pyobservablejs` views render in JupyterLab, marimo, VS Code notebooks, Google
Colab, and other [anywidget](https://anywidget.dev/) hosts. The live examples
use marimo and require Python 3.11 or newer.

```sh
uvx --with pyobservablejs marimo edit notebook.py
```

```marimo-config
requires-python = ">=3.11"
dependencies = ["pyobservablejs"]
```

```python marimo echo=false server-output=false
import marimo as mo
import observablejs as obs
```

## Load an existing Observable notebook

`Notebook.from_observablehq` loads a public ObservableHQ notebook as a Python
`Notebook`. Call `view()` to create its renderable notebook view.

```python
import observablejs as obs

notebook = obs.Notebook.from_observablehq("@d3/world-tour")
notebook.view()
```

`@d3/world-tour` resolves to
[observablehq.com/@d3/world-tour](https://observablehq.com/@d3/world-tour).
See [Import ObservableHQ notebooks](create/observablehq.mdx) for accepted
specifiers, network behavior, and pinned source revisions.

## Author an interactive notebook

Combine HTML, Observable JavaScript, and Notebook Kit JavaScript cells in one
notebook. Changing the species input recomputes the plot in the browser.

```python
import observablejs as obs

notebook = obs.Notebook(
    obs.html(
        """
        <h2>Palmer penguins</h2>
        <p>Choose a species to filter the chart.</p>
        """
    ),
    obs.ojs(
        """
        viewof species = Inputs.select(
          ["All", ...new Set(penguins.map((d) => d.species))],
          {label: "Species", value: "All"}
        )
        """,
    ),
    obs.js(
        """
        Plot.dot(
          species === "All"
            ? penguins
            : penguins.filter((d) => d.species === species),
          {
            x: "culmen_length_mm",
            y: "culmen_depth_mm",
            fill: "species",
            tip: true
          }
        ).plot({
          height: 320,
          color: {legend: true},
          x: {grid: true, label: "Bill length (mm)"},
          y: {grid: true, label: "Bill depth (mm)"}
        })
        """,
    ),
)

notebook.view()
```

JavaScript [`viewof` operator](https://observablehq.com/@observablehq/views)
updates `species` when the selection changes.

## Sync values with Python

Pass Python values to the browser through `variables`. A named `viewof` input
with the same name starts from the Python value and reports browser interactions
through the rendered view.

```python
import observablejs as obs

notebook = obs.Notebook(
    obs.ojs(
        """
        viewof threshold = Inputs.range([0, 1], {
          value: 0.75,
          step: 0.05,
          label: "Threshold"
        })
        """
    ),
    obs.js('html`<p>Threshold: <strong>${threshold}</strong></p>`'),
    variables={"threshold": 0.75},
)

notebook_view = notebook.view()
notebook_view
```

```python marimo echo=false server-output=false
variables_notebook = obs.Notebook(
    obs.ojs(
        """
        viewof threshold = Inputs.range([0, 1], {
          value: 0.75,
          step: 0.05,
          label: "Threshold"
        })
        """
    ),
    obs.js('html`<p>Threshold: <strong>${threshold}</strong></p>`'),
    variables={"threshold": 0.75},
)

variables_view = variables_notebook.view()
mo.ui.anywidget(variables_view)
```

While the view stays mounted,
`notebook.update_variables(threshold=0.9)` updates the control from Python.
After the view renders, `notebook_view.values["threshold"]` reads its current
browser value.
