# API reference

The `observablejs` package exports notebook definitions, renderable views,
cell constructors, synchronized value records, and dependency graph records.

```python
import observablejs as obs

notebook = obs.Notebook(
    obs.md("# Summary"),
    obs.ojs("answer = 40 + 2", key="answer"),
)
full_view = notebook.view()
```

## Public exports

| Export                                                      | Kind              | Contract                                                                         |
| ----------------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------- |
| [`Notebook`](notebook.mdx)                                  | Class             | Owns the definition, attachments, theme, variables, and shared input values.     |
| [`NotebookView`](notebook-view-and-cell.mdx#notebookview)   | Class             | Renders selected cells and owns its browser runtime, values, and graph snapshot. |
| [`NotebookCell`](notebook-view-and-cell.mdx#notebookcell)   | Class             | Identifies one cell by index, optional key, and optional Notebook Kit name.      |
| [`Cell`](cell-helpers.mdx#cell)                             | Frozen data class | Describes one Python-authored Notebook Kit cell and its metadata.                |
| [`ojs`](cell-helpers.mdx#helper-functions)                  | Function          | Creates an Observable JavaScript `Cell`.                                         |
| [`js`](cell-helpers.mdx#helper-functions)                   | Function          | Creates a JavaScript module `Cell`.                                              |
| [`md`](cell-helpers.mdx#helper-functions)                   | Function          | Creates a Markdown `Cell`.                                                       |
| [`html`](cell-helpers.mdx#helper-functions)                 | Function          | Creates an HTML `Cell`.                                                          |
| [`CellValues`](values-and-graph.mdx#cellvalues)             | Frozen data class | Carries the synchronized values for one selected cell.                           |
| [`NotebookGraph`](values-and-graph.mdx#notebookgraph)       | Frozen data class | Contains decoded cells and symbolic dependency edges.                            |
| [`CellInfo`](values-and-graph.mdx#cellinfo)                 | Frozen data class | Describes one cell in a synchronized graph snapshot.                             |
| [`DependencyEdge`](values-and-graph.mdx#dependencyedge)     | Frozen data class | Describes one variable dependency between two cells.                             |
| [`NotRenderedError`](values-and-graph.mdx#notrenderederror) | Exception         | Reports that the browser snapshot required for readback has not synchronized.    |
| [`NOTEBOOK_THEMES`](themes.mdx)                             | Tuple             | Lists the accepted Notebook Kit theme names.                                     |

The reference pages cover these related entry points:

- [Variables and serialization](variables-and-serialization.mdx) defines
  both directions of value serialization and the variable update lifecycle.
- [Source constructors](source-constructors.mdx) defines the
  `Notebook.from_*` constructors.
- [File attachments](file-attachments.mdx) defines `files`, `base_path`, and
  `FileAttachment` resolution.
- [Themes](themes.mdx) defines accepted theme names and validation.
