# Reference

The `observablejs` package exports notebook definitions, renderable views,
cell constructors, synchronized value records, and dependency graph records.

```python
import observablejs as obs

notebook = obs.Notebook(
    obs.md("# Summary"),
    obs.ojs("answer = 40 + 2", key="answer"),
)
full_view = notebook.view()
```

## Public exports

| Export                                                      | Kind              | Contract                                                                           |
| ----------------------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------- |
| [`Notebook`](notebook.mdx)                                  | Class             | Owns the Notebook Kit definition, attachments, variables, and shared input values. |
| [`NotebookView`](notebook.mdx#notebookview)                 | Class             | Renders a cell selection and owns its browser runtime, values, and graph snapshot. |
| [`Cell`](cells.mdx#cell)                                    | Frozen data class | Describes one Python-authored Notebook Kit cell.                                   |
| [`ojs`](cells.mdx#cell-helpers)                             | Function          | Creates an Observable JavaScript `Cell`.                                           |
| [`js`](cells.mdx#cell-helpers)                              | Function          | Creates a JavaScript module `Cell`.                                                |
| [`md`](cells.mdx#cell-helpers)                              | Function          | Creates a Markdown `Cell`.                                                         |
| [`html`](cells.mdx#cell-helpers)                            | Function          | Creates an HTML `Cell`.                                                            |
| [`NotebookCell`](notebook.mdx#notebookcell)                 | Class             | Selects one notebook cell and creates a view through `view()`.                     |
| [`CellValues`](values-and-graph.mdx#cellvalues)             | Frozen data class | Carries the synchronized values for one selected cell.                             |
| [`NotebookGraph`](values-and-graph.mdx#notebookgraph)       | Frozen data class | Contains decoded cells and symbolic dependency edges.                              |
| [`CellInfo`](values-and-graph.mdx#cellinfo)                 | Frozen data class | Describes one cell in a synchronized graph snapshot.                               |
| [`DependencyEdge`](values-and-graph.mdx#dependencyedge)     | Frozen data class | Describes one variable dependency between two cells.                               |
| [`NotRenderedError`](values-and-graph.mdx#notrenderederror) | Exception         | Reports that the browser snapshot required for readback has not synchronized.      |
| [`NOTEBOOK_THEMES`](notebook-themes.mdx)                    | Tuple             | Lists the accepted Notebook Kit theme names.                                       |

The reference pages cover these related entry points:

- [Variables](variables.mdx) defines both directions of value serialization and
  the variable update lifecycle.
- [File attachments](file-attachments.mdx) defines `files`, `base_path`, and
  `FileAttachment` resolution.
- [Source notebooks](source-notebooks.mdx) defines the `Notebook.from_*`
  constructors.
