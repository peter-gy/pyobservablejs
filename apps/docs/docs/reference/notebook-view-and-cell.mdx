# `NotebookView` and `NotebookCell`

`NotebookView` is the anywidget display object for a full, focused, or
composite selection. `NotebookCell` is the stable handle that selects one
cell.

## `NotebookCell`

`NotebookCell` identifies one cell in a notebook definition. Its `key` and
`name` attributes expose the optional Python key and Notebook Kit name.
`index` is the cell's zero-based position. Handles come from
[`Notebook.cell`](notebook.mdx#notebookcellselector) and
[`Notebook.cells`](notebook.mdx#notebookcells).

```python
cell = notebook.cell("answer")
print(cell.index, cell.key, cell.name)
answer_view = cell.view()
```

### `NotebookCell.view()`

Returns a new `NotebookView` selected to this cell. The view owns its
browser runtime, graph, and synchronized values. The selected cell renders
while its dependency closure evaluates with hidden output.

## `NotebookView`

`Notebook.view()` and `NotebookCell.view()` create `NotebookView` objects.
The browser runtime starts when an anywidget host mounts the view.

```python
full_view = notebook.view()
full_view
```

marimo wraps each view with `mo.ui.anywidget`. Most other hosts display the
view directly.

```python
import marimo as mo

widget = mo.ui.anywidget(full_view)
```

### Notebook and selection

| Member     | Contract                                           |
| ---------- | -------------------------------------------------- |
| `notebook` | The `Notebook` that created this view.             |
| `cells`    | Selected `NotebookCell` handles in notebook order. |

Mutate Python variables through `view.notebook` or the original `Notebook`.
Variable changes apply to every active view from that notebook.

A `NotebookView` owns one live writable output. Create another view from the
notebook when the same selection must appear in two outputs at once. A view
can render again after its previous output is torn down.

### Browser lifecycle

| State                   | `has_rendered` | `has_graph_snapshot` | Available readback                          |
| ----------------------- | -------------- | -------------------- | ------------------------------------------- |
| Created                 | `False`        | `False`              | View selection                              |
| Graph synchronized      | `False`        | `True`               | Graph metadata                              |
| Selected cells rendered | `True`         | `True`               | Values, per-cell values, and graph metadata |

A variable replacement or release that triggers a runtime rebuild clears
both gates until the replacement graph and render snapshots synchronize.

### `NotebookView.has_rendered`

Returns whether the browser has synchronized a completed render for this
view.

### `NotebookView.has_graph_snapshot`

Returns whether this view has synchronized graph metadata.

### `NotebookView.graph`

```python
graph: obs.NotebookGraph = full_view.graph
```

Returns the decoded immutable graph snapshot for the cells evaluated by this
view. A selected view includes its selected cells and their dependency
closure. It raises `NotRenderedError` before graph synchronization.

### `NotebookView.values`

```python
values: dict[str, object] = full_view.values
```

Returns a new dictionary of decoded values from this view. Names produced by
more than one selected cell are omitted because they have no unique owner.
The property raises `NotRenderedError` before the view renders.

### `NotebookView.cell_values`

```python
values: tuple[obs.CellValues, ...] = full_view.cell_values
```

Returns one `CellValues` record per selected cell in notebook order. It
raises `NotRenderedError` before the view renders.

### `NotebookView.close()`

Closes this display model and removes it from the notebook's active views.
Other views from the notebook remain active. Repeated calls are no-ops, and
previously synchronized readback remains available.

See [Values and graph records](values-and-graph.mdx) for decoded value types
and graph records.
