# Python to Observable

`variables` gives Python ownership of named values in the Observable graph.
`update_variables` changes those values while the view stays mounted, and
every cell that references the name runs again.

Move the minimum body mass slider and the chart filters the built-in Palmer
Penguins sample.

```marimo-config
requires-python = ">=3.11"
dependencies = ["pyobservablejs"]
```

```python
import marimo as mo
import observablejs as obs

minimum_mass = mo.ui.slider(
    start=3000,
    stop=6000,
    step=250,
    value=4000,
    label="Minimum body mass (g)",
)
```

```python marimo echo=false server-output=false
import marimo as mo
import observablejs as obs

minimum_mass = mo.ui.slider(
    start=3000,
    stop=6000,
    step=250,
    value=4000,

)
```

```python
notebook = obs.Notebook(
    obs.js(
        """
        const selectedPenguins = penguins.filter(
          (d) => d.body_mass_g >= minimumMass
        );
        """,
        key="selected_penguins",
        display=False,
    ),
    obs.js(
        """
        Plot.barX(
          selectedPenguins,
          Plot.groupY(
            {x: "count"},
            {
              y: "species",
              fill: "species",
              tip: {fill: "var(--marimo-island-background)"}
            }
          )
        ).plot({
          height: 240,
          marginLeft: 76,
          color: {legend: true},
          x: {grid: true, label: "Penguins at or above the threshold"},
          y: {label: null}
        })
        """,
        key="chart",
    ),
    variables={"minimumMass": 4000},
)

full_view = notebook.view()
widget = mo.ui.anywidget(full_view)
```

notebook.update_variables(minimumMass=minimum_mass.value)

```python marimo echo=false server-output=false
notebook.update_variables(minimumMass=minimum_mass.value)

```

The final cell updates one Python-owned variable and returns the existing
`widget`. The notebook session sends the value to `full_view`, and Notebook
Kit invalidates the two JavaScript cells that depend on `minimumMass`.
Variable updates reach every active view from the notebook, not just this
one.

## What crosses the wire

Values serialize recursively. Plain values stay JSON; richer values keep
their browser type through tagged records:

```python
import datetime as dt

notebook.update_variables(
    releasedAt=dt.date(2026, 7, 17),   # JavaScript Date
    payload=b"\x00\x01",               # Uint8Array
    bigCounter=2**60,                  # BigInt
)
```

pandas and Polars are first-class: a `DataFrame` arrives as an array of row
objects, a `Series` as an array, and NumPy arrays and scalars convert through
`tolist()` and `item()`.

```python
import polars as pl

frame = pl.DataFrame({"species": ["Adelie", "Gentoo"], "count": [152, 124]})
notebook.update_variables(speciesCounts=frame)  # [{species: "Adelie", ...}, ...]
```

The full conversion table, identifier rules, and reserved names live in
[Variables and serialization](../reference/variables-and-serialization.mdx).
For large tables and binary data, prefer [file
attachments](../create/files-and-modules.mdx), which the browser loads
through `FileAttachment` readers instead of widget state.

## Update, replace, or release

`update_variables` merges values into the current set of Python-owned names.

```python
notebook.update_variables({"minimumMass": 3500})
notebook.update_variables(minimumMass=4500)
```

`replace_variables` replaces the Python-owned variable mapping. A name absent
from the replacement returns to its notebook definition.

```python
notebook.replace_variables({"minimumMass": 4000})
```

`reset_variables` releases selected names.

```python
notebook.reset_variables("minimumMass")
```

Releasing a name rebuilds each active runtime so the original notebook
definition resumes ownership; see [Manage view
lifecycle](../render/view-lifecycle.mdx#rebuilds-reset-the-gates). Updates
that do not change the serialized value are no-ops.

Continue with [Observable to Python](observable-to-python.mdx) for the
reverse direction, and [Bidirectional inputs](bidirectional-inputs.mdx) for
Python variables that share a name with browser inputs.
