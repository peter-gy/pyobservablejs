# Bidirectional inputs

When a Python variable and named `viewof` input use the same name, the initial
Python value sets the control. Browser changes update sibling views. A later
Python update sets the value again in every view.

```marimo-config
requires-python = ">=3.11"
dependencies = ["pyobservablejs"]
```

Use separate marimo cells for the Python slider, notebook, and update.

```python
import marimo as mo
import observablejs as obs

python_gain = mo.ui.slider(start=0, stop=12, value=5, label="Gain from Python")
```

```python
notebook = obs.Notebook(
    obs.ojs(
        'viewof gain = Inputs.range([0, 12], {value: 5, step: 1, label: "Gain in the browser"})',
        key="gain_control",
    ),
    obs.js(
        """
        Plot.barY(
          Array.from({length: 8}, (_, index) => (index + 1) * gain),
          {
            x: (_, index) => index + 1,
            y: (value) => value,
            tip: {
              // This example references a theme variable used by mdx-marimo.
              // Replace it with a CSS color or remove `fill` in another host.
              fill: "var(--marimo-island-background)"
            }
          }
        ).plot({height: 220, x: {label: "Step"}, y: {grid: true}})
        """,
        key="chart",
    ),
    variables={"gain": 5},
)

view = notebook.view()
widget = mo.ui.anywidget(view)
```

```python
notebook.update_variables({"gain": python_gain.value})
mo.vstack([python_gain, widget])
```

The value moves in four steps:

1. The initial Python value sets the input.
2. Changing the browser input updates sibling views.
3. `update_variables({"gain": value})` sets a new Python value in every view.
4. `reset_variables("gain")` returns the value to the notebook definition.

Shared input state supports JSON-like values, `BigInt`, dates, maps, and sets.
Functions, DOM elements, files, and binary buffers stay in the view where they
were created. Use the same input shape for a shared name across views.

Read the current browser result through `view.state.result("gain_control")`.
See [Widget composition](../render/widget-composition.mdx) for separate views
and [Variables and
serialization](../reference/variables-and-serialization.mdx#shared-viewof-inputs)
for the value boundary.
