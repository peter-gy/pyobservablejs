# pyobservablejs and pyobsplot

[`pyobsplot`](https://github.com/juba/pyobsplot) turns Python Plot
specifications into Observable Plot figures, including widget and static output
formats. `pyobservablejs` embeds Notebook Kit notebooks made from reactive
JavaScript, Observable JavaScript, Markdown, and HTML cells, with selected views
and Python state synchronization. Choose based on whether the unit you are
building is a Plot figure or a notebook.

`pyobsplot` informed the Python variable API in `pyobservablejs`.
