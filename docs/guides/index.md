# Guides

These pages are organized by the workflow you are building.

- [Python variables](python-variables.md) passes Python values into Observable
  and updates them without remounting the widget.
- [Cell values](cell-values.md) reads browser-synchronized values and graph
  metadata after render.
- [Source HTML](source-html.md) loads Notebook Kit HTML with local
  `FileAttachment` files.
- [Author cells](author-cells.md) covers `obs.ojs`, `obs.js`, `obs.md`, and
  `obs.html`.
- [ObservableHQ imports](observablehq.md) fetches a public ObservableHQ notebook
  and overrides variables from Python.
- [Themes](themes.md) applies Notebook Kit themes and source panels.
- [Notebook frontends](notebook-frontends.md) shows Jupyter and marimo display
  patterns.
